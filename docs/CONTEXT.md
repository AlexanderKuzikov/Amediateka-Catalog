## Open-проблемы

| # | Priority | Описание |
|---|----------|----------|
| 1 | medium | У части новинок 2026 года нет IMDb/Кинопоиска — внешние источники не подключены, рейтинги берутся только из API Amediateka |
| 2 | medium | Автообновление работает только при включённом ПК и входе пользователя; пропущенный запуск выполняется при следующем включении (StartWhenAvailable) |
| 3 | low | 6 тайтлов без стран в detail-ответе: «Просто, как вода», «Равные условия», «Вечер профессионального бокса Кости Цзю», «Майкл Джексон и его история», «Пока смерть не разлучит нас», «Адюльтер» |
| 4 | low | Деплой на Sat ручной (`scripts/deploy.ps1`), в месячную сборку не встроен: после `npm run monthly` файл нужно заливать отдельно |
| 5 | low | «Новое за месяц» считается по `publicationDate`; обновление метаданных на платформе может подсветить старый тайтл как новый |
| 6 | low | У фильмов «Соловей» и «Дети шоу-бизнеса» нет длительности — в формате показывается «фильм» |
| 7 | low | При частичном сбое detail-запросов `fetch.mjs` всё равно сохраняет снимок: пропуски по этим тайтлам останутся до следующего месяца, в логе будет WARN |
